# AI 软件开发工作流

你正在协助完成一个完整的 AI 软件开发项目。严格按照以下四阶段顺序执行：架构设计 → 代码生成 → 审查优化 → 开发运行。

## 工作流参数

在开始之前，请确认以下配置参数（如未提供则使用默认值）：

- **项目名称**: `one-sentence-generate-page`
- **技术栈**: Vue 3 + Vite + TypeScript
- **UI 库**: UnoCSS
- **状态管理**: Pinia
- **热重载**: 启用
- **调试工具**: 启用
- **最大重试次数**: 3
- **自动回滚**: 启用

## 阶段 1: Architect（架构设计）

切换到 Architect 模式，深度解析用户需求，输出完整的技术架构方案。

### 执行步骤

1. **需求深度解析**
   - 分析用户输入的提示词，提取核心功能需求
   - 识别非功能需求（性能、安全、可维护性）
   - 列出约束条件和边界情况

2. **技术架构设计**
   - 设计系统整体架构
   - 划分核心模块，定义模块职责
   - 设计数据流和模块依赖关系
   - 选择合适的技术栈和库

3. **项目目录结构设计**
   - 设计项目目录结构
   - 定义各目录职责和文件规范
   - 确保符合 Vue 3 + Vite 项目最佳实践

4. **核心模块划分**
   - 列出需要开发的组件清单
   - 定义页面组件和功能组件
   - 设计 API 服务层结构
   - 规划状态管理模块

5. **接口设计**
   - 设计 API 接口（请求/响应格式）
   - 定义错误处理机制
   - 设计类型定义（TypeScript interfaces）

### 输出要求

完成本阶段后，输出以下内容：
- 技术架构方案说明
- 项目目录结构树
- 核心模块划分清单
- 技术栈选型理由
- API 接口设计文档

### 模式切换

完成架构设计后，使用 `new_task` 工具切换到 Orchestrator 模式，传递架构方案作为输入。

---

## 阶段 2: Orchestrator（执行编排）

切换到 Orchestrator 模式，按架构方案逐项生成代码、配置依赖、编写构建脚本并完成基础集成。

### 执行步骤

1. **代码生成**
   - 按架构方案逐项生成代码文件
   - 生成核心组件（Header、Footer 等）
   - 生成页面组件
   - 生成 API 服务代码
   - 生成状态管理代码
   - 生成工具函数代码

2. **依赖配置**
   - 检查并更新 `package.json`
   - 安装项目依赖
   - 配置构建工具

3. **构建脚本配置**
   - 配置 `vite.config.ts`
   - 配置 `tsconfig.json`
   - 配置 ESLint/Prettier（如需要）
   - 配置 UnoCSS

4. **基础集成**
   - 配置 Vue Router
   - 配置 Pinia 状态管理
   - 配置全局样式
   - 确保项目可正常运行

### 执行规则

- 每个文件生成后，使用 `read_file` 验证内容
- 确保所有代码符合 TypeScript 类型要求
- 遵循 Vue 3 Composition API + `<script setup>` 规范
- 使用 UnoCSS 原子类，禁止内联样式

### 模式切换

完成代码生成后，使用 `new_task` 工具切换到 Review 模式，传递已生成的代码清单作为输入。

---

## 阶段 3: Review（审查优化）

切换到 Review 模式，对已实现代码进行静态分析、逻辑校验与边界测试，精准识别缺陷与性能瓶颈，并依据审查建议自动重构或修复。

### 执行步骤

1. **静态分析**
   - 运行类型检查（`vue-tsc --noEmit`）
   - 运行代码 lint（`eslint`）
   - 检查未使用的导入和变量
   - 检查类型定义完整性

2. **逻辑校验**
   - 校验业务逻辑正确性
   - 检查数据流完整性
   - 检查错误处理机制
   - 检查边界条件处理

3. **边界测试**
   - 空值处理测试
   - 异常输入测试
   - 并发处理测试
   - 响应式边界情况

4. **性能分析**
   - 检查潜在的重渲染问题
   - 检查 bundle 大小
   - 检查懒加载配置
   - 检查组件拆分合理性

### 优化动作

根据审查结果，执行以下优化：
- **代码重构**: 根据审查建议重构代码
- **缺陷修复**: 修复识别的缺陷
- **性能优化**: 优化性能瓶颈

### 输出要求

完成本阶段后，输出：
- 代码审查报告
- 优化建议清单
- 修复后的代码清单

### 模式切换

完成审查优化后，使用 `new_task` 工具切换到 Code 模式，准备启动开发服务器。

---

## 阶段 4: Dev（开发运行）

切换到 Code 模式，启动本地开发服务器，配置热重载与调试工具，自动打开预览页面并输出访问地址与运行状态日志。

### 执行步骤

1. **启动开发服务器**
   - 执行 `npm run dev`
   - 等待服务器就绪
   - 获取访问地址

2. **配置热重载**
   - 验证文件监听功能
   - 验证自动刷新功能

3. **配置调试工具**
   - 配置浏览器开发者工具
   - 配置 Vue DevTools

4. **打开预览页面**
   - 使用 `browser_action` 打开浏览器
   - 导航到首页
   - 截取初始状态截图

### 输出要求

完成本阶段后，输出：
- 开发服务器访问地址
- 运行状态日志
- 预览页面截图

## 状态追踪

工作流执行过程中，请跟踪以下状态：

| 状态 | 描述 |
|------|------|
| `initialized` | 工作流已初始化 |
| `stage-1-running` | 架构设计阶段执行中 |
| `stage-1-complete` | 架构设计阶段完成 |
| `stage-2-running` | 执行编排阶段执行中 |
| `stage-2-complete` | 执行编排阶段完成 |
| `stage-3-running` | 审查优化阶段执行中 |
| `stage-3-complete` | 审查优化阶段完成 |
| `stage-4-running` | 开发运行阶段执行中 |
| `completed` | 工作流全部完成 |

## 异常处理

- **阶段失败**: 回滚到上一个检查点，最多重试 3 次
- **依赖安装失败**: 检查网络状态，尝试更换镜像源
- **构建失败**: 检查配置文件，修复语法错误
- **服务器启动失败**: 检查端口占用，尝试更换端口
